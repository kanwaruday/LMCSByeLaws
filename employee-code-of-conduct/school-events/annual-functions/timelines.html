B. Timelines

Deadlines updated 2026-09-18 per OO-11/26 — Performance & Song Selection, Annual Function Preparation, and Event Flow all moved; Theme Selection and Dress Finalisation unchanged.

Key Deadlines

  • Theme Selection: Before last week of March (New Year Preparation week)
  • Performance & Song Selection: 1st week of April (previously 31st March)
  • Annual Function Preparation: 20–30 working days before the Annual Function (previously April month & 30 working days before)
  • Event Flow: 20–30 working days before Annual Function (previously 60 working days before)
  • Dress Finalisation: 60 working days before Annual Function
